# product-management-api-146581-146687

This workspace contains the Products Backend: a .NET 8 minimal API exposing CRUD endpoints for products.

- Container: products_backend
- Docs: http://localhost:3001/docs
- Health: GET http://localhost:3001/

Endpoints:
- GET /api/products/
- GET /api/products/{id}
- POST /api/products/
- PUT /api/products/{id}
- DELETE /api/products/{id}
